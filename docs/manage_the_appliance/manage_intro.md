# Managing the Appliance

The appliance is built on Ubuntu Linux. But you don't have to be a terminal user to deploy and maintain the appliance. The appliance has a built-in web interface where you can accomplish most tasks needed to finish configuring the appliance after the setup script finishes. You can also perform most day to day management tasks from the GUI. The following sections explain how.
